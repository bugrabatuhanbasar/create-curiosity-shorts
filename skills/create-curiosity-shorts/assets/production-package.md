# Final production package template

Use the user's output language. Fill every required section; mark genuinely inapplicable sections instead of omitting them. Use short tables and scene cards. Place the selected recording script before detailed production logistics.

1. PROJECT: package version, status PROVISIONAL/PLANNED/EDIT READY, pillar, topic, one question, answer, language/audience, duration, constraints and explicit assumptions. Give blockers early.
2. OPENING: selected first frame, first spoken sentence, overlay, promise, selection reason and one backup opening with asset feasibility.
3. CLEAN NARRATION: recording-only text, no IDs/citations/directions. Shorter fallback separately. Word count, speed assumption, speech estimate, pause budget, total duration and measured/estimated status.
4. CLAIM MAP: sentence IDs to claim IDs; verified and unresolved separated. Source details with scope/date checked and actual URL.
5. TIMELINE: scene ID, start/end/duration, sentence or exact fragment. Sum shown.
6. SCENE CARDS: viewer takeaway; exact voice fragment; visible object/action; framing; material IDs/type/status; exact overlay; justified motion/mark; transition/cue; truthful low-cost fallback.
7. MATERIALS: deduplicated IDs, scenes, required detail, availability, inspection, URL or search terms in appropriate languages, rights/attribution status and fallback. Never conflate source evidence and media license.
8. DIAGRAM/AI PROMPTS: exact diagram parts/ratios or English copy-ready prompts for needed AI scenes; consistency, start/action/end and checks. Write “AI video not required” where appropriate.
9. EDIT AND WORKLOAD: Premiere/After Effects split, dependent tasks, human-minute ranges, completion checks, mandatory/optional separation, cap comparison, simplification.
10. REVIEW: defects fixed and unresolved by priority, structural checks, untested real-media checks, voice/phone preview checklist.
11. PUBLICATION: three truthful titles, one selected, short description, actual attribution notes, AI disclosure check if relevant. No upload by default.
12. LEARNING AND HANDOFF: one measurable hypothesis, comparable-metric plan, current version and remaining work. Keep stable IDs for revision.

If file output is requested, create production-package.md, project-state.json and production-package.json with schema fields. JSON is the machine-checkable summary; Markdown retains the full scene cards and prompts. Do not claim producing a video file.
