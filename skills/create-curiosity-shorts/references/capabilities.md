# Capability routing

Before execution note whether the current host can browse/open sources, inspect video/audio, write files and run Python. Skills are instructions; they do not add these tools, buy credits, access a private repository or call separate models by themselves.

Without browsing, use supplied content as supplied-unverified unless reliable inspection is possible; provide research tasks and provisional wording. Without footage inspection, mark candidates uninspected. Without code, manually check arithmetic and label the validator not run. Without file tools, deliver complete content in chat and never link nonexistent files. Do not ask for an API key for this instruction-only workflow.

Generate no images, videos or narration automatically unless user authorization covers generation and spend. A request for a production plan authorizes prompts and planning, not purchases or uploads. Use existing generation tools if explicitly requested; otherwise list intended assets. Do not hardcode a particular Google AI Pro quota, model availability or ElevenLabs price. Look up current official documentation when those affect a decision.

When a repository is only read through links, read SKILL.md and required references before claiming to follow the package. If nested files cannot be retrieved, request the ZIP or pasted missing content. This is in-session instruction use, not a persistent installation. Pin a commit/release for repeatable tests when possible.
