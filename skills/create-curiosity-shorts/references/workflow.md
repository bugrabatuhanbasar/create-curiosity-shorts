# Detailed production workflow

## Research ledger
For each I01 claim retain exact wording, pillar, source title/URL, relevant section or extract location, date checked, scope, conflicts and status. Use verified only after inspecting sufficient evidence. Use supplied-unverified, unresolved, contradicted or removed otherwise. Prefer institutions, manufacturers, universities and research. Repeated copies are not independent corroboration. Do not collect unnecessary personal data.

Identify the opening visual, the key explanatory motion and final result early. Search phrases are not acquired footage. For each M01 material record actual availability and rights status separately. A government site or stock search result is not a blanket license. Save exact attribution requirements if known.

## Hook and narrative
Draft diverse first image/first sentence pairs: detail, direct surprising fact, visible result, scale estimate or a supported misconception. Judge clarity, promise/evidence match and feasibility. Select one and a backup without mandatory user approval. An early answer can create a how/why continuation. Do not withhold one word to pad the explanation. Avoid generic greetings, branding intros and empty calls to keep watching.

Develop identification, minimal orientation, explanatory causal steps, visible payoff and concise closure. Adjust order to the subject. Every sentence should add a fact or link needed for understanding. Keep a clean recording script and a separate sentence-to-claim map. Store a short fallback. Record estimated speech rate and pause budget; recalculate after narration arrives. Word count is whitespace-separated tokens for planning, not a linguistic measurement.

## Timeline
For a tentative 35-second structure, opening 0–3, orientation 3–8, explanation 8–23, payoff 23–32 and closure to 35 can be a starting sketch. Do not treat these as algorithm rules. Each scene must use actual end minus start; preserve no gaps/overlaps and exact planned total. A narration text may span scenes: map sentence fragments clearly instead of duplicating narration and counting it twice. Mark all unmeasured timings as estimated.

Scene cards must define viewer takeaway, voice text, exact visible action, subject/model/species, framing/focus, material ID/type/status, overlays, justified edit/motion, transition, optional cue and fallback. If detail footage is unavailable, show a truthful labeled original diagram or narrow the question. Do not use unrelated stock footage where the answer must be demonstrated.

## Asset and AI plan
Deduplicate by material ID. Priority: existing files, licensed real media, original diagrams, AI stills, AI video. Search in relevant languages; give only actually found URLs. For an AI scene provide an English ready-to-use prompt with subject, setting, framing, light, reference consistency, vertical composition and text-free space. For motion add initial state, one main action, camera behavior, end state and requested duration. Avoid model-specific parameters unless verified; support negative constraints in plain language if no negative field. Record planned attempts, not fictional completed generations. State zero prompts if AI adds no value.

## Production workload
Order research, critical-media acquisition, script lock, narration, rough edit, custom explanation, text/audio polish, preview and export. Give low/high human-minute estimates with reasons and dependencies. If time cap exists, compare total high estimate and offer reduced scope where necessary. Separate required work from optional enhancements. Costs are unknown unless grounded; no-new-purchases can be satisfied with an alternative but does not mean all tools are free. Do not promise an asset can be obtained within a fixed time.

## Review and revision
Inspect inputs honestly: text, storyboard, actual audio, stills or playable render. Record critical/important/optional issues with IDs and fixes. Core unsupported claims, wrong species/model, false visual evidence, infeasible required footage and unfulfilled promise block final ready status. Repair script and dependent timeline/assets together. Maintain draft version and change summary. Provide provisional useful work if sources/tools block completion.

## Publication and learning
Give three accurate titles, concise description with actual source/attribution details and one next-video hypothesis. Never publish without instruction. Recheck current YouTube policy when advice depends on it. For measured outcomes record publication age, duration, traffic, engaged views, stayed-to-watch, average duration/percentage, retention graph and comparable videos. Observe at consistent intervals such as 48 hours, 7 days and 28 days; these do not mark the end of distribution. Use medians as well as averages. Small samples do not establish causality. Avoid reupload experiments masquerading as controlled A/B tests.
